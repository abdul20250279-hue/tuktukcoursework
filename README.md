Malabe Tuk-Tuk & Three-Wheeler Spares Depot

What is this project?

This is a **JavaFX desktop application** for a spare parts shop in Malabe, Sri Lanka. It helps the shop owner manage inventory, dealers, and sales.

Technologies Used

| Technology 
|-----------
| Java 
| JavaFX
| JUnit
| Scene Builder
| Git 

 How to Run the Application

### Step 1: Open in IntelliJ
1. Open IntelliJ IDEA
2. Click **File → Open**
3. Select the project folder

### Step 2: Configure JavaFX
1. Go to File → Project Structure → Libraries
2. Click → Java
3. Add the JavaFX SDK folder
